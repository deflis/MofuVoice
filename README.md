# もふボイス (MofuVoice)

**思考を邪魔しない「超低遅延モニタリング」と、外部プラグイン不要の「オールインワン音声処理」を兼ね備えた、配信者・ストリーマーのためのリアルタイム・ボイスチェンジャー**

> **遅延で脳がバグらない。プラグインの迷路で迷わない。**  
> 話した瞬間に思い通りの声になるから、ゲーム実況もおしゃべりも思いのまま。  
> 準備はこれひとつで完了。さあ、最高に可愛い声で配信をはじめよう。

「もふボイス」は、声の遅延による思考停止やトークのもたつきを極限まで排除した、男声から自然で聞き取りやすい女声への変換に対応するボイスチェンジャーです（英語名称: MofuVoice。「Morph Voice」をもとに「もふ」の響きを加えた名称）。マイクの吹かれ・環境ノイズ対策から、サ行の刺さり抑制、叫び声の音割れ防止まで、配信に必要な音作りがこれ1本で完結します。

---

## 主な特徴

- **思考や会話を妨げない超低遅延モニタリング（最大の強み）**  
  標準の位相ロック方式では約 10.7 ms（512サンプル / 48 kHz）の極小DSP遅延を実現。変換後の声をヘッドホンで聴きながら話しても、遅延によって思考や発話が邪魔されず、いつものペースでスムーズに会話やゲーム実況を続けられます。
- **これ1台で配信の音作りが完結するオールインワンDSP**  
  外部のDAWや追加プラグインを一切用意することなく、配信クオリティの音声処理が本アプリ単体で完結します。
  - **マイク・部屋のノイズ対策**: 吹かれや机の振動を抑える 80 Hz HPF、部屋鳴りを抑える反響低減、打鍵音・ファン音をカットするノイズゲート
  - **声の聞き取りやすさ・聴感の向上**: 「さ行」の耳刺さりを抑えるディエッサー、独立した3系統のEQ（入力 / 変換前 / 変換後）
  - **配信向け音量バランス**: 叫び声の音割れを防ぐピーク保護、小声を聞きやすく持ち上げるコンプレッサー・自動音量調整（Auto Level）
  - **空間演出**: 雑談や歌枠に自然な空気感を加えるリバーブ
- **配信者向け・男声→女声変換に特化した音質設計**  
  配信で聞き取りやすく、自然で滑らかな女声質を目指してチューニングされた独自のDSPアルゴリズムを実装。声の高さ（ピッチ）とフォルマントを直感的に調整できます。
- **ASIO対応 & 配信ソフトとのシームレスな連携**  
  Windows ではオーディオインターフェースの低遅延 **ASIO** を直接サポート。Voicemeeter や VB-Audio Matrix などの仮想ミキサーと連携し、OBS Studio や Discord へ最小遅延で音声をルーティングできます（macOS / Linux にも対応）。
- **シンプルなGUI & 設定の自動保存**  
  ワンクリックでモノラル／ステレオを選択可能。調整したパラメータは終了時に自動保存され、次回の配信時もすぐに同じ設定でスタートできます。

## 3分クイックスタート

1. **アプリを起動してデバイスを選ぶ**  
   アプリを起動し、**「設定」** → **「音声デバイス」** でお使いのマイクとヘッドホンを選びます（通常は **モノラル（1 → 1）** を選択）。
2. **元の声で音出し確認**  
   設定ウィンドウで **「設定を保存」** を押し、メイン画面で **「音声を開始」** を押します。マイクに向かって話し、ヘッドホンから自分の声が遅延なく聞こえることを確認します。
3. **声を変える**  
   **「音声を停止」** を押してから、**「声を調整する」** で **「声の高さ（ピッチ）」** を `+7` 〜 `+9`、**「フォルマント」** を `+3` 〜 `+4` 程度に上げて **「設定を保存」** します。再度 **「音声を開始」** して声の変化を確かめてみましょう。

詳しい手順は **[はじめてのセットアップガイド](docs/quickstart.md)** をご覧ください。
