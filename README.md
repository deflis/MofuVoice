# もふボイス (MofuVoice)

名称は「Morph Voice」をもとに、「もふ」の響きを加えて変形させたものです。

配信・通話向けのリアルタイム・ボイスチェンジャーです。GUIでマイクとヘッドホンを選び、ピッチやフォルマントを直感的に調整して自然な声（男声→女声など）へ変換できます。

---

## 主な特徴

- **声の高さとフォルマントを個別に調整**  
  声の高さ（ピッチ）と響きの太さ・明るさ（フォルマント）をそれぞれ −12 〜 +12 半音で自由にコントロール。フォルマントを保ったままピッチだけを変えたり、女性らしい明るい響きを付加したりできます。
- **思考を妨げない低遅延設計**  
  標準の位相ロック方式では約 10.7 ms（512サンプル / 48 kHz）の極小DSP遅延を実現。ヘッドホンで変換後の自分の声をモニタリングしながらでも、違和感なくスムーズに会話や配信を行えます。
- **配信に必要な音声処理をオールインワン搭載**  
  マイクの吹かれ・振動音を抑える 80 Hz HPF、部屋鳴りを抑える反響低減、ノイズゲート、サ行の耳刺さりを抑えるディエッサー、3系統の独立EQ、音量を均一化するコンプレッサー・自動音量調整、リバーブまで、配信に必要なエフェクトを網羅。
- **使いやすいGUI & 設定の自動保存**  
  複雑な設定なしでワンクリックでモノラル／ステレオを切り替え可能。調整したパラメータは終了時に自動保存され、次回起動時もすぐに同じ設定で再開できます。
- **ASIO & クロスプラットフォーム対応**  
  Windows ではオーディオインターフェースの低遅延 **ASIO** を直接サポート。Windows（WASAPI）、macOS（CoreAudio）、Linux（ALSA）の標準サウンド（CPAL）にも対応しています。
- **配信ソフト・通話アプリとの連携**  
  Voicemeeter や VB-Audio Matrix などの仮想オーディオデバイスと連携し、OBS Studio や Discord、ゲーム配信へ簡単に変換音声を届けられます。

## 3分クイックスタート

1. **アプリを起動してデバイスを選ぶ**  
   アプリを起動し、**「設定」** → **「音声デバイス」** でお使いのマイクとヘッドホンを選びます（通常は **モノラル（1 → 1）** を選択）。
2. **元の声で音出し確認**  
   設定ウィンドウで **「設定を保存」** を押し、メイン画面で **「音声を開始」** を押します。マイクに向かって話し、ヘッドホンから自分の声が遅延なく聞こえることを確認します。
3. **声を変える**  
   **「音声を停止」** を押してから、**「声を調整する」** で **「声の高さ（ピッチ）」** を `+7` 〜 `+9`、**「フォルマント」** を `+3` 〜 `+4` 程度に上げて **「設定を保存」** します。再度 **「音声を開始」** して声の変化を確かめてみましょう。

詳しい手順は **[はじめてのセットアップガイド](docs/quickstart.md)** をご覧ください。
