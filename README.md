# Rust Low-Latency Voice Changer

配信・通話向けのリアルタイムボイスチェンジャーです。GUIでマイクと出力先を選び、声の高さやフォルマントを調整できます。

## 特徴

- **声の高さとフォルマントを個別に調整**：声の高さ（ピッチ）とフォルマントをそれぞれ−12〜+12半音で指定できます。フォルマントを保持したピッチ変更にも対応します。
- **声を整える音声処理**：ランブルフィルター、ノイズゲート、3バンドEQ、ディエッサー、自動音量調整、コンプレッサーを利用できます。
- **GUIで操作・設定を保存**：デバイス選択から音声調整まで画面上で行え、保存した設定は次回起動時に復元します。
- **Windows・macOS・Linuxの音声入出力に対応**：標準の音声バックエンド（CPAL）に加え、WindowsではASIOを利用できます。
- **配信ソフトと連携**：VoicemeeterやVB-Audio Matrixで、変換した声を通話・録音・配信へ送れます。

ピッチ・フォルマント変換のDSP遅延はウィンドウ設定で変わります。標準設定では、位相ロック（標準）とスペクトル位相同期（`pvsola-sync`）が約10.67 ms（48 kHz・512サンプル）、TD-PSOLA、TD-PSOLA＋リサンプリング、FD-PSOLAが112 ms（5376サンプル）です。TD-PSOLAとFD-PSOLAで独立したフォルマント移動を使う場合は合成ウィンドウ長が加わります。PVSOLAは固定96 ms（4608サンプル）です。実際の遅延には、デバイスや音声の接続経路による遅延も加わります。

## GUIでの使い方

使用するサンプリングレートの音声入出力に対応したデバイスと、GUIの実行ファイルを用意してください。WindowsではWebView2 Runtimeも必要です。ソースコードから作成する場合は[ビルド手順](DEVELOPMENT.md)を参照してください。

### 1. マイクと出力先を選ぶ

アプリを起動して **設定** を押し、**音声デバイス** で使う機器を選びます。ASIOでは、選んだ機器にヘッドホンを接続してください。

チャンネルは **モノラル（1 → 1）** または **ステレオ（1 → 1, 2）** をワンクリックで選べます。それ以外の割り当てやバッファサイズなどは **詳細設定** を開きます。**サンプリングレート** は44.1・48 kHzから選べます（既定値48 kHz）。高レートはピッチ・フォルマント処理の品質検証が済むまで選択できません。入力・出力が共通して対応するレートを選び、ASIOではドライバー側も同じレートに揃えてください。変更は次の音声開始時に反映されます。配信向けの接続例は[Voicemeeter](docs/voicemeeter.md)・[VB-Audio Matrix](docs/vbmatrix.md)のガイドを参照してください。

### 2. 声を聴く

**設定を保存** を押し、メイン画面の **音声を開始** を押します。マイクに向かって話し、出力先から声が聞こえることを確認してください。

### 3. 声を変える

**音声を停止** を押してから、メイン画面の **声を調整する** を押します。**声の高さ** と **フォルマント** のスライダーを少しずつ動かしてください。**元の声に戻す** で、2つの調整を戻せます。

**設定を保存** を押してから、**音声を開始** で聞き比べます。細かな数値調整は **詳細設定** から行えます。

気になる雑音には **雑音を減らす**、声の音色や音量には **声を整える** を使います。機能をオンにすると、その調整項目が表示されます。

### 4. 停止・保存する

**音声を停止** で音声処理を停止します。設定ウィンドウを閉じるときにも自動保存します。次回起動時に設定を復元しますが、音声処理は **音声を開始** を押すまで始まりません。

## 困ったとき

- **声が聞こえない**：入力・出力デバイス、チャンネル、出力先への接続を確認します。
- **元の声と変換した声が重なる**：デバイスの直接モニターや、未処理マイクを出力する経路を確認します。
- **音が途切れる**：設定の **音声デバイス → 詳細設定** で、デバイスの対応範囲内でバッファサイズを大きくして試します。
