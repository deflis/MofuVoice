# Rust Low-Latency Voice Changer

配信・通話向けのリアルタイムボイスチェンジャーです。GUIでマイクと出力先を選び、声の高さや響きを調整できます。

## 特徴

- **声の高さと響きを個別に調整**：PitchとFormant shiftをそれぞれ−12〜+12半音で指定できます。フォルマントを保持したピッチ変更にも対応します。
- **声を整える音声処理**：低域ノイズ除去、ノイズゲート、3バンドEQ、ディエッサー、自動音量調整を利用できます。
- **GUIで操作・設定を保存**：デバイス選択から音声調整まで画面上で行え、保存した設定は次回起動時に復元します。
- **Windows・macOS・Linuxの音声入出力に対応**：標準の音声API（CPAL）に加え、WindowsではASIOを利用できます。
- **配信ソフトと連携**：VoicemeeterやVB-Audio Matrixで、変換した声を通話・録音・配信へ送れます。

ピッチ・フォルマント変換のDSP遅延は約10.67 ms（48 kHz・512サンプル）です。実際の遅延には、デバイスや音声の接続経路による遅延も加わります。

## GUIでの使い方

48 kHzの音声入出力に対応したデバイスと、GUIの実行ファイルを用意してください。WindowsではWebView2 Runtimeも必要です。ソースコードから作成する場合は[ビルド手順](DEVELOPMENT.md)を参照してください。

### 1. 起動してデバイスを選ぶ

`rust-low-latency-voice-changer-gui`（Windowsでは `.exe`）を起動し、**設定** を開きます。

- **音声API**：既定は「自動（ASIO優先）」。ASIOの場合は **ASIO device**、標準（CPAL）の場合は **入力デバイス** と **出力デバイス** を選びます。
- **入力・出力チャンネル**：マイクが届く入力と、声を送る出力を選びます。既定は入力1 → 出力1です。出力は複数選択できます。
- **Frames**：まずは既定の **512** を使います。

デバイス側のサンプルレートも **48 kHz** にそろえてください。出力先はヘッドホンや配信用の音声入力へ接続します。出力を入力へ戻す接続は避けてください。配信向けの接続例は[Voicemeeter](docs/voicemeeter.md)・[VB-Audio Matrix](docs/vbmatrix.md)のガイドを参照してください。

### 2. 元の声で動作を確認する

最初は **Pitch = 0**、**Formant shift = 0**、**Preserve formants = オン** のまま、その他の音声処理をオフにします。

設定画面を **閉じる** で閉じ、**Inspect** を押します。詳細表示が `Inspection OK` になったら **Start** を押し、マイクに向かって話して出力先から声が聞こえることを確認します。Inspectだけでは音声処理は始まりません。

### 3. 声を変える

**Stop** を押し、停止が完了したら **設定** を開いて調整します。

| 設定 | 効果・試し方 |
| --- | --- |
| **Pitch** | 声の高さ。まず `+3`（3半音高くする）や `−3`（3半音低くする）を試します |
| **Preserve formants** | オンにすると、ピッチ変更時に元の声の響きを保つ補正を行います |
| **Formant shift** | 声の響き。Preserve formantsをオンにして、まず±2〜3半音で調整します |

設定画面を閉じて **Start** で再開し、聞きながら少しずつ調整してください。設定を変えるときは **Stop → 設定変更 → Start** の順で操作します。

必要に応じて、低い唸りには **低域ノイズ除去**、無音時のノイズには **Noise gate**、音色には **EQ**、サ行の刺さりには **サ行をやわらかくする**、音量のばらつきには **Auto level** を使えます。詳しい調整方法は[詳細な使い方](docs/usage.md)を参照してください。

### 4. 停止・保存する

**Stop** で音声処理を停止します。設定画面の **設定を保存** で保存でき、ウィンドウを閉じるときにも自動保存します。次回起動時に設定を復元しますが、音声処理は **Start** を押すまで始まりません。

## 困ったとき

- **声が聞こえない**：入力・出力デバイス、チャンネル、出力先への接続を確認します。
- **元の声と変換した声が重なる**：デバイスの直接モニターや、未処理マイクを出力する経路を確認します。
- **音が途切れる**：詳細表示のエラーを確認し、デバイスの対応範囲内でFramesを大きくして試します。
