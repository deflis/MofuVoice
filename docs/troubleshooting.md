# 困ったとき（トラブルシューティング）

[READMEに戻る](../README.md) / [はじめてのセットアップ](quickstart.md)

音が出ない、ノイズが入る、声が二重になるなどの問題が発生したときの対処法をまとめています。

---

## 1. 音が出ない・マイクが反応しない

| 原因の可能性 | 確認・対処法 |
| :--- | :--- |
| **音声処理が開始されていない** | メイン画面で **「音声を開始」** を押してください。「音声処理中」と表示されている間のみ音が流れます |
| **デバイスが正しく選択されていない** | 設定ウィンドウの **「音声デバイス」** で、実際にマイクが接続されている機器（入力）とヘッドホン（出力）が選ばれているか確認してください |
| **チャンネル割り当てのズレ** | マイクが接続されている入力チャンネルが選択されているか確認してください（通常は **モノラル（1 → 1）** または **ステレオ（1 → 1, 2）**） |
| **OS側のマイク権限やミュート** | Windowsの「設定 → プライバシーとセキュリティ → マイク」でアプリへのアクセスが許可されているか、またマイク自体の物理ミュートスイッチを確認してください |

---

## 2. 元の声（生声）と変換した声が混ざって二重に聞こえる

| 原因の可能性 | 確認・対処法 |
| :--- | :--- |
| **オーディオインターフェースの直接モニター** | インターフェース本体の **Direct Monitor（ダイレクトモニター）** スイッチやつまみがONになっていないか確認してください。これがONだと、PCを通る前のマイクの生音がヘッドホンから直接聞こえてしまいます |
| **OBSやDiscordでの二重取り込み** | 配信ソフトや通話ソフトのマイク入力に「マイクの生デバイス」と「ボイスチェンジャーを通した仮想デバイス」の両方が指定されていないか確認してください |
| **Voicemeeter / Matrix のルーティング** | 仮想ミキサー側でマイクの生音がヘッドホン（A1）や配信出力（B1）に直接バイパスされていないか確認してください |

---

## 3. 音がプチプチ途切れる・警告が出て停止する

| 原因の可能性 | 確認・対処法 |
| :--- | :--- |
| **バッファサイズが小さすぎる** | 設定ウィンドウの **「音声デバイス → 詳細設定」** で、**バッファサイズ（サンプル）** を現在の値（例: 256や512）から大きめの値（例: 512や1024）に増やしてください |
| **サンプリングレートの不一致** | 本アプリ、オーディオインターフェース、Windowsのサウンド設定、仮想ミキサーのサンプリングレートがすべて **48000 Hz（48 kHz）** に揃っているか確認してください |
| **ASIOドライバの競合** | ASIOドライバの多くは1つのアプリしか占有できません。DAW（Cubase, Studio Oneなど）や他の音声ソフトが同じASIOドライバを開いていないか確認してください |

---

## 4. 声が機械的（ケロケロ・ロボット声）になる・歪む

| 原因の可能性 | 確認・対処法 |
| :--- | :--- |
| **マイク入力でクリッピングしている** | マイクのゲイン（入力音量）が大きすぎて、声を入れた瞬間に赤色クリップしていないか確認してください。少しゲインを下げると自然になります |
| **ピッチやフォルマントの上げすぎ** | 声の高さ（ピッチ）を+12など極端に上げると、破綻しやすくなります。まずは `+7` 〜 `+9` 程度に抑え、自分の地声側も少し高めに発声してみてください |
| **ノイズゲートのしきい値が高すぎる** | ゲートが厳しすぎると、声の出始めや語尾が途切れ、ロボットのような不自然な途切れ方になります。ゲートのしきい値を下げるか、一旦ゲートをOFFにして確認してください |

---

## 5. 遅延（レイテンシ）が大きく感じる

| 原因の可能性 | 確認・対処法 |
| :--- | :--- |
| **ピッチ変換方式の設定** | 設定の **「声の変換 → 詳細設定 → ピッチ変換方式」** が `FD-PSOLA` や `TD-PSOLA` になっている場合、アルゴリズム由来の遅延（約112 ms）が発生します。超低遅延でモニターしたい場合は **「位相ロック（標準）」**（約10.7 ms）を選択してください |
| **バッファサイズが大きすぎる** | バッファサイズを大きくしすぎると全体遅延が増えます。音が途切れない範囲で、512または256サンプルまで詰めてみてください |
| **仮想オーディオケーブルの内部遅延** | VB-Cable や Voicemeeter などの内部バッファ設定が原因の場合があります。各ツールの設定でサンプル数（256〜512サンプル）を確認してください |

---

## 6. 設定が保存されない・起動エラーになる

| 原因の可能性 | 確認・対処法 |
| :--- | :--- |
| **設定の保存操作をしていない** | パラメータ変更後は、設定ウィンドウ内の **「設定を保存」** ボタンを押してください（ウィンドウを閉じる際にも自動保存されます） |
| **設定ファイル（settings.ini）の破損** | アプリと同じフォルダにある `settings.ini` を削除（または別名に移動）してアプリを再起動すると、初期設定でクリーンに立ち上がります |
| **書き込み権限がない** | アプリの実行ファイルが `Program Files` などの書き込み権限が制限されたフォルダにある場合、設定の保存に失敗することがあります。ユーザーフォルダ配下に配置して実行してください |
