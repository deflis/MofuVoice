# はじめてのセットアップガイド

[READMEに戻る](../README.md)

もふボイスを起動し、マイクの音声を変換してヘッドホンから出力するまでの最短手順を説明します。

---

## 必要なもの・動作環境

- **OS**: Windows 10/11（64bit）、macOS 15以降、または Linux（X11／Wayland、Vulkan環境）
- **マイク・ヘッドホン**: 変換した声を聞くため、スピーカーではなくヘッドホンやイヤホンの使用を推奨します
- **オーディオ環境**:
  - Windows では **ASIO** 対応のオーディオインターフェース、または仮想オーディオソフトウェア（Voicemeeter / VB-Audio Matrix など）の利用を推奨します
  - Windows標準のサウンドデバイス（WASAPI）や、macOS（CoreAudio）、Linux（ALSA）でも動作します（設定では **「標準」** バックエンド）

---

## ステップ 1: アプリを起動する

1. `MofuVoice.exe`（または各OSの実行ファイル）を起動します。
2. メイン画面が表示されます。
3. メイン画面の **「設定」** ボタンを押すと、独立した設定ウィンドウが開きます。

> [!TIP]
> 設定ウィンドウは開いたままメイン画面を操作できます。設定を変更した後は、設定ウィンドウ内の **「設定を保存」** ボタンを押すことで反映されます。

---

## ステップ 2: 音声デバイスを選ぶ

設定ウィンドウの **「音声デバイス」** を開きます。

1. **音声バックエンドの選択**:
   - **「詳細設定」** を開き、**「音声バックエンド」** を確認します。通常は **「自動」** のままで問題ありません。
   - Windows で ASIO 対応ドライバがある場合は自動的に ASIO が使われます。それ以外、および macOS / Linux では **「標準」** が使われます。明示的に切り替える場合は **「標準」** を選びます（Windows では **「ASIO」** も選択できます）。
2. **デバイスの指定**:
   - **ASIOの場合**: **「入出力デバイス」** で使用するインターフェースを選択します（例: オーディオインターフェースのASIOドライバやVoicemeeterなど）。
   - **標準の場合**: **「入力デバイス」**（マイク）と **「出力デバイス」**（ヘッドホンや仮想ケーブル）をそれぞれ選択します。**「システムの既定」** を選ぶとOSの既定デバイスを使用します。
     - 配信用の仮想オーディオデバイスなどへ出力しながら自分でも聴く場合は、**「モニター出力デバイス」** に別のヘッドホンを選びます。変換後の同じ音声をモニター先の全チャンネルに出力します。不要な場合は **「なし」** を選びます。モニターには別途バッファと機器の遅延が加わります。
     - 入力と出力で音声形式（16bit整数・32bit整数・32bit浮動小数点）が異なる場合は、自動で変換します。
3. **チャンネル割り当て**:
   - **「入力チャンネル（1つ選択）」** でマイクが接続されているチャンネルを選びます。通常は **`1ch`** です。
   - **「出力チャンネル（複数選択可）」** でヘッドホンや仮想ケーブルへ出すチャンネルを選びます。片耳／モノラルなら **`1ch`**、ステレオヘッドホンで両耳から聞きたい場合は **`1ch`** と **`2ch`** の両方を選びます。
4. **サンプルレートとバッファサイズ**:
   - **「サンプルレート」** は **48000**（48 kHz）を推奨します。
   - 画面には **「入出力で変換なしに使えるレート」** が表示されます（**「標準」** バックエンドでは **「入力の対応レート」**・**「出力の対応レート」** も表示されます）。遅延を抑えるには、**「入出力で変換なしに使えるレート」** に載っている値を選び、入出力デバイス側も同じレートに揃えてください。
   - **「標準」** バックエンドでは、選択レートに非対応の入出力を自動でリサンプリングします。変換により遅延が追加されるため、可能な限り変換なしで使えるレートを選んでください。
   - **「詳細設定」** の **「バッファサイズ（サンプル）」** は **512** を目安に設定します。

---

## ステップ 3: 元の声で音出しを確認する（原音テスト）

まずは声を変えずに、正常に音声が入出力されているかを確認します。

1. 設定ウィンドウで **「設定を保存」** を押します。
2. メイン画面に戻り、**「音声を開始」** を押します。
3. 画面に **「動作中」** と表示されます。
4. マイクに向かって声を出してみて、ヘッドホンから自分の声が遅延なく自然に聞こえるか確認してください。

> [!NOTE]
> 初期状態（ピッチ 0、フォルマント 0、各種エフェクトOFF）では、入力された音声がそのまま出力されます。

もし声が聞こえない場合や音が途切れる場合は、[困ったとき（トラブルシューティング）](troubleshooting.md) を確認してください。

---

## ステップ 4: 声を変えてみる

1. メイン画面で **「音声を停止」** を押します（音声処理中は設定の変更ができません）。
2. メイン画面の **「声を調整する」**（または設定ウィンドウの **「声の変換」**）を開きます。
3. **「声の高さ（半音）」** と **「フォルマント（半音）」** のスライダーを動かします。
   - **声の高さ**: `+7` 〜 `+10` 前後に上げると声が高くなります。
   - **フォルマント**: `+3` 〜 `+5` 前後に上げると、女性らしい明るい響きになります。
4. **「設定を保存」** を押してから、再度 **「音声を開始」** を押します。
5. 変換された声を聞きながら、自然に聞こえる好みの位置に微調整していきます。
