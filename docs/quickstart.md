# はじめてのセットアップガイド

[READMEに戻る](../README.md)

もふボイスを起動し、マイクの音声を変換してヘッドホンから出力するまでの最短手順を説明します。

---

## 必要なもの・動作環境

- **OS**: Windows 10/11（64bit）、macOS、または Linux
- **マイク・ヘッドホン**: 変換した声を聞くため、スピーカーではなくヘッドホンやイヤホンの使用を推奨します
- **オーディオ環境**:
  - Windows では **ASIO** 対応のオーディオインターフェース、または仮想オーディオソフトウェア（Voicemeeter / VB-Audio Matrix など）の利用を推奨します
  - Windows標準のサウンドデバイス（WASAPI）や、macOS（CoreAudio）、Linux（ALSA）でも動作します

---

## ステップ 1: アプリを起動する

1. `MofuVoice.exe`（または各OSの実行ファイル）を起動します。
2. メイン画面が表示されます。
3. メイン画面の **「設定」** ボタンを押すと、独立した設定ウィンドウが開きます。

> [!TIP]
> 設定ウィンドウは開いたままメイン画面を操作できます。設定を変更した後は、設定ウィンドウ内の **「設定を保存」** ボタンを押すことで反映されます。

---

## ステップ 2: 音声デバイスを選ぶ

設定ウィンドウの **「音声デバイス」** を開きます。

1. **音声バックエンドの選択**:
   - 通常は **「自動（ASIO優先）」** のままで問題ありません。
   - ASIO機器をお使いの場合は自動的にASIOが使われます。
2. **デバイスの指定**:
   - **ASIOの場合**: **「入出力デバイス」** で使用するインターフェースを選択します（例: オーディオインターフェースのASIOドライバやVoicemeeterなど）。
   - **CPALの場合**: **「入力デバイス」**（マイク）と **「出力デバイス」**（ヘッドホン）をそれぞれ選択します。「システムの既定」を選ぶとOSの既定デバイスを使用します。
3. **チャンネル割り当て**:
   - 通常のマイク入力であれば、まずは **「モノラル（1 → 1）」** を選びます。
   - ステレオヘッドホンで両耳から聞きたい場合は **「ステレオ（1 → 1, 2）」** を選びます。
4. **サンプリングレートとバッファサイズ**:
   - サンプリングレートは **48000 Hz（48 kHz）** を推奨します（デバイス側も同じレートに合わせてください）。
   - バッファサイズは **512サンプル** を目安に設定します。

---

## ステップ 3: 元の声で音出しを確認する（原音テスト）

まずは声を変えずに、正常に音声が入出力されているかを確認します。

1. 設定ウィンドウで **「設定を保存」** を押します。
2. メイン画面に戻り、**「音声を開始」** を押します。
3. 画面に「音声処理中」と表示されます。
4. マイクに向かって声を出してみて、ヘッドホンから自分の声が遅延なく自然に聞こえるか確認してください。

> [!NOTE]
> 初期状態（ピッチ 0、フォルマント 0、各種エフェクトOFF）では、入力された音声がそのまま出力されます。

もし声が聞こえない場合や音が途切れる場合は、[困ったとき（トラブルシューティング）](troubleshooting.md) を確認してください。

---

## ステップ 4: 声を変えてみる

1. メイン画面で **「音声を停止」** を押します（音声処理中は設定の変更ができません）。
2. メイン画面の **「声を調整する」**（または設定ウィンドウの「声の変換」）を開きます。
3. **「声の高さ（ピッチ）」** と **「フォルマント」** のスライダーを動かします。
   - **声の高さ**: `+7` 〜 `+10` 前後に上げると声が高くなります。
   - **フォルマント**: `+3` 〜 `+5` 前後に上げると、女性らしい明るい響きになります。
4. **「設定を保存」** を押してから、再度 **「音声を開始」** を押します。
5. 変換された声を聞きながら、自然に聞こえる好みの位置に微調整していきます。
